Computer Vision Assignment  – Canny & Harris Feature Detectors

This project implements and analyzes two fundamental feature detection algorithms — the Canny Edge Detector and the Harris Corner Detector — using Python (OpenCV).
The goal is to evaluate their performance, robustness, and invariance under variations in image scale and intensity (contrast).

 Key Highlights

Implemented in Python (OpenCV) using VS Code

Comparative analysis of Canny and Harris algorithms

Tested on 3 distinct images: natural, urban, and person/object

Evaluated across 4 variations each (resolution & contrast)

Includes automatic parameter tuning, visualization, and PDF report generation

 Techniques Used

Grayscale conversion & 8-bit quantization

Image scaling & intensity transformation

Canny Edge Detection

Harris Corner Detection

Histogram Equalization

OpenCV-based visualization & analysis

 Output

The project generates:

Processed images (edges & corners)

Summary report (experiment_summary.txt)

Auto-generated PDF report (ComputerVision_Assignment1_Report.pdf)
